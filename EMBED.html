Add an award to your site

Free to use. No script, no account, no cookies.

Every award plaque of this site can be shown on another website: the same plate, the same fonts and colours, one line of HTML. Copy the code under the award you want (one tap or click selects it) and paste it into your page where the plaque should appear. The plaque is a link to its award page here.

How it works

The code is a standard <iframe>. It scales to the width of its container (up to 504 px) and keeps its proportions, so it fits phones and computers alike. Use the Light code on a light page and the Dark code on a dark page. Works in any site builder that accepts custom HTML (WordPress, Tilda, Wix, Squarespace, Notion embeds, plain HTML).
